# つながる！大陸の生態系

食物連鎖を見て、1年に1回だけ動物を増やす・移す判断をする短いパズルゲームです。

## 遊び方

1. 生き物カードの「現在数」と「適正範囲」を比べます。
2. 「増やす」「移す」「何もしない」から1回の行動を決めます。
3. 「1年進める」で変化と理由を確認します。
4. 全生物を適正範囲に2年続けて保つとクリアです。

植物とうさぎから始まり、ステージごとにきつね、鹿、おおかみが加わります。計算は決定的で、同じ状態と行動なら同じ結果になります。

## 起動

外部ライブラリやビルドは不要です。静的サーバーでリポジトリを公開するか、`index.html` をブラウザで開いてください。

```sh
python3 -m http.server 8000
```
