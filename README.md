# 生態系バランス

食物連鎖と生態系ピラミッドの「安定するバランス」を探す、スマホ向けWebシミュレーションゲームのMVPです。

## 入っているもの
- 植物
- 草食動物 小・中・大
- 肉食動物 小・中・大
- 種ごとの繁殖スピード
- 餌不足による繁殖低下・餓死
- 捕食
- 自然死
- 植物の回復
- 年3回の介入
- 生態系安定度
- 10年間の安定維持でクリア
- 年ごとの増減理由
- 小さなランダム環境イベント

## 起動
`index.html` をブラウザで開くだけで動きます。

GitHub Pagesに置く場合は、3ファイルをリポジトリ直下にアップロードしてPagesを有効化してください。
